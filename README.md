Установка
Для установки зависимостей проекта, используйте одну из следующих команд:

С помощью Poetry
Убедитесь, что у вас установлен Poetry.
Выполните команду:

poetry install

С помощью Makefile
Если у вас установлен make, вы можете использовать следующую команду: 

make install

Запуск
Чтобы запустить проект, выполните одну из следующих команд:

С помощью Poetry

poetry run project

С помощью Makefile

make project
